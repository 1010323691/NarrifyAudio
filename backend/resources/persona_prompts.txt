# description：音色描述
用一两句中文，只写声音本身、在任何一句台词里都成立的声学特征：性别、年龄段、音色、音高、语速、语调、口音/方言、整体质感（温暖/冷淡、清亮/沙哑、利落/舒缓等）。
- 以"年龄段 + 男性/女性"开头，如"青年男性""中年女性""少年男性""老年女性"，必须出现"男性"或"女性"二字。
- 性别和年龄按上下文中的身份信息判断：代词和关系称谓（他/她、男友/女友、哥哥/妹妹、老师/同学）、身份和年龄线索（学生、孩子、老人、明确的年龄或年级）。上下文完全没有这些线索时，才根据说话方式推断，并选不带特征的中性默认值，不要习惯性写"青年"。
- 年龄段按人的身份定，不按说话是否老练定：学生是"少年"或"青少年"，孩子是"儿童"，绝不是"青年"——十六岁的学生说话再成熟也是"青少年"；老人是"老年"。
- 只描述固定的声音，不描述这个人：不写性格、身份、经历、人际关系、剧情作用；也不写随情境变化的语气（如"紧急时语气变得急促"）。年龄只写成声音的年龄段（"青少年"可以，"他是一名学生"不行）。
- 每个特征都必须对这个角色说的任何一句话成立；只适合某个场景或某种情绪的特征要删掉。
- 好的例子："青年男性，音色清亮，音高中偏高，语速偏快，语调轻快上扬。" / "少年男性，音色清亮略带稚气，音高偏高，语速偏快。"
- 坏的例子："性格外向幽默，紧急时语气变得急切严肃，重情重义。"（描述的是人和多变的情绪，不是固定的声音）

# ref_text：参考音频文本
一段 40–60 字的中文（朗读约 12–15 秒），用这个角色平常说话的口吻。它会被合成为克隆全书声音的参考音频，所以要能代表角色的日常说话方式。
- 写一句连贯的话，或两句相连的短句；可以借用、改写或拼接其台词，不必逐字照抄。
- 语气平稳自然：不要哭喊、尖叫、呻吟、大笑等强烈情绪，不要省略号、拟声词、成串的语气词，不要英文、数字、生僻字。
- 严格控制在 40–60 字，绝不超出。

# gender
"male" 或 "female"，与 description 依据同一条身份线索。上下文完全没有性别线索时写 "unknown"（description 仍按说话方式写一个更可能的性别）。

# 特殊角色
- 「{speaker}」是 NARRATOR（旁白）时：设计适合长时间收听的叙述声音——音色清晰稳定、语速适中、语调平和、有叙事感。第一人称叙述（"我"）时，性别、年龄与"我"的身份一致；否则选与本书风格相称的成熟叙述声音。ref_text 写一段平实的叙述。
- 非人角色（系统、AI、广播等）：按原文对它的描写设计声音质感，如"中年男性，冷静平板的电子合成音，语速均匀，几乎没有起伏。"
