# 制作进度快照

项目列表和当前项目的制作总览共用 `project_progress` 数据库表。`summary?progress=true` 的完整读取、`text`、`catalog` 和 `production` 分区读取都从这一行返回阶段计数，不在 HTTP 请求内遍历成果目录或读取脚本、清单、音频。

没有快照时显示未知进度，并提交非计费的 `project.progress` 机械 Worker 任务。同一项目并发请求共用一个在途任务。Worker 复用实际成果覆盖率算法，更新快照与任务成功状态在同一事务中提交，租约失效的执行不能覆盖快照。该任务不影响项目卡片的制作状态，在任务中心资源管理分区显示为“更新制作进度”。

HTTP 仅检查固定数量的目录/声音配置元数据和项目任务的最新更新时间，变化时返回已有快照并提交后台重建。正在制作时快照可能短暂落后于实时任务进度；下一次轮询会继续检查并更新。工作区外部修改还会按五分钟时间窗口触发校准，嵌套音频的手动修改可能等到下一窗口才被发现。没有页面读取时不会为了刷新快照启动扫描。

部署需升级到 Alembic `0024_project_progress`，并同时更新 API 和 Worker。已有项目首次打开时后台建立快照；Worker 未运行时会保留已有数据或显示未知，不在 API 内同步回退扫描。后台任务失败后，读取可以在新的三十秒重试窗口重新提交。

验证覆盖首次读取不扫描、分区并发只建一个任务、跨请求复用数据库数据、删除脚本后重建、旧执行拒绝发布，以及项目卡片和制作总览完整/分区接口共用快照。
