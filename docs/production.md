# 制作第一本有声书

[中文首页](../README.zh-CN.md) · [English home](../README.md) · [English guide](production.en.md)

本指南面向普通用户，说明从原稿到可领取成品的操作顺序。安装应用请先阅读 [Windows 部署](windows.md)或 [Linux 部署](../readme-linux.md)；服务启停、备份与故障处理见[运维指南](operations.md)。

## 开始前

管理员从 `/#/admin/login` 登录管理控制台，配置存储、LLM、TTS 和用户额度。普通用户从 `/#/login` 登录制作工作台。两个门户使用不同角色权限；管理员账号不能代替普通用户账号进入制作工作台。

先用短篇原稿走通一章，再处理整本书：

| 制作能力 | 需要的条件 |
| --- | --- |
| 项目管理、文本排版、分册与章节核对 | 应用、数据库、队列与 Worker 池已启动 |
| 文本解析、角色声音基础、BGM 段落分析 | 管理员配置可访问的 LLM，账号有足够额度 |
| 候选音色、台词合成、单句重新生成 | 本地 TTS 环境和模型可用，账号有足够额度 |
| 音频探测、合并与混音 | FFmpeg、ffprobe 和共享 `.venv` 音频依赖可用（合并需要 pydub）；混音还需音乐库 |

远程 LLM 不要求本机 CUDA。本地 TTS 的 GPU、环境和模型安装按部署指南完成；引擎文件存在不等于模型已经可以真实合成。

## 1. 创建项目并整理原稿

在「我的项目」创建项目，进入项目工作台。各制作页面使用当前活动项目；处理不同书籍时先切换项目。项目总览显示阶段进度、在途任务和需要处理的失败项，可从这里继续制作。

进入「排版与分册」，点击「添加源文档」上传 TXT 或 EPUB。可以多选或继续添加；多个文件按列表顺序合成一本书，处理前可上移、下移或移除。刷新后可以恢复上次处理的源文档列表。

EPUB 按书内阅读顺序提取正文，保留上传的原文件；图片、字体和导航不作为正文。暂不支持加密正文、纯图片扫描版或 OCR，也没有 PDF、DOCX 原稿导入入口。

在「处理设置」选择：

- **智能分册**：识别章节后拆分；没有识别到章节时自动按目标字数分册。
- **按字数分册**：按目标字数拆分全文，切点落在段落或句子边界附近。

还可设置句末断行、对话分段、空格与标点整理。点击「开始处理」后，后台依次完成排版、章节分析与分册，生成供后续解析使用的章节文本。

## 2. 核对章节

在章节列表检查编号、标题、正文和核对原因，查看自动调整情况，对需要检查的章节逐一核对并保存标记。智能处理只能辅助发现和修复异常；重复编号、漏章、标题误识别等仍需要人工确认。

可搜索、筛选、分页浏览并查看章节详情。处理和核对状态会保存，离开页面后可以回来继续。重新处理会产生新的章节版本；旧分册或解析结果可能被判定为已覆盖或陈旧，应先确认当前版本再继续。

## 3. 解析角色与台词

进入「文本解析」，选择待解析、失败、全部或筛选范围内的章节，点击「开始解析」。输出为按章节组织的角色、台词与语音指导数据，可对照原文检查结果。

「解析检查项」提供内容完整性、断句异常、超长段落、角色归属、语音指导和角色归属抽查。设置只影响之后提交的任务，已提交任务沿用提交时的配置。检查可以尝试修复问题，但不能保证所有角色和台词都判断正确。

排版与分册正在运行、源内容已变化或同章已有解析任务时，提交可能被阻止。按页面提示先完成上游处理或刷新状态；失败章节可单独重试，无需重新解析全书。

## 4. 制作并选择角色声音

「角色配音」分为两个阶段：

1. **语音推理基础**：LLM 根据角色台词和上下文生成声音描述与参考文本。可按角色重做，并使用自定义声音描述。
2. **候选音色**：本地 TTS 根据声音基础生成候选参考音频。逐个试听并选择合适的候选，所选声音用于后续台词合成；未显式选择时使用默认候选。

页面支持修改角色性别标记、单角色重新制作、补齐缺少的基础或候选，以及手动合并角色。角色关联提示仅供参考，不会自动把相似姓名当成同一个人物；确认是同一角色后再合并。

这里的候选声音由模型根据描述生成；不要把此流程理解为上传任意真人录音后自动克隆。候选生成可能部分成功，应检查每个角色的状态和实际试听效果。

## 5. 合成台词音频

进入「音频合成」，先核对角色声音，再选择章节和合成范围。通常先补齐未完成段落；需要全面重做时使用重新生成全部的操作，并确认页面对重置已有结果的提示。

后台按台词生成独立音频，页面显示章节完成数、部分完成和失败情况。没有可合成台词的解析文件不能直接合成。角色音色变化后也应检查已有段落是否仍匹配当前声音配置。

先完成一章并试听，确认声音和语音指导有效，再扩大制作范围。合成片段属于制作资料；要领取成品还需完成合并或其他交付阶段。

## 6. 逐句预览和修订

「整章预览」支持逐句试听，修改台词、角色和语音指导，并单句重新生成。没有独立单句音频时，页面可能回退播放整章合并音频，此时不会定位到对应台词。

修改先保存在当前编辑状态；重新生成的音频是暂存预览，试听满意后再保存。每条修改必须有与当前文本、角色、语音指导一致的成功重渲染结果，才能保存到正式章节。

**保存会更新本章正式脚本与段音频，并使已有章节合并音频、BGM 混音和段落时间轴失效。** 修订后重新合并，再检查或重做相关音乐时间轴与混音。遇到同章合成、合并或保存冲突时，先等待当前操作结束。

## 7. 合并章节与扩展处理

### 合并为整章

进入「音频合并」，核对输入完整性后选择就绪章节提交。只有完整合成的章节可以提交；首次合并生成章节 MP3，重新合并会覆盖所选章节旧结果。完成后试听，检查台词衔接和整章效果。

### 可选：背景音乐

「背景音乐」直接使用章节合并人声。先匹配曲目或手动选曲，再核对段落和时间轴，最后混音与试听。可使用整章随机匹配，也可让 LLM 分析段落；基于已有分析重算段落时间轴本身不调用 LLM。

混音需要合并人声和可用曲目。修改台词、重新合并、调整曲目或段落后，先核对当前时间轴和人声是否一致，再提交混音；同章正在制作时页面可能阻止冲突操作。

## 8. 跟踪任务与领取成品

### 任务中心

长时制作由后台 Worker 执行，可以离开页面并稍后回来继续查看。关闭浏览器不会等同于取消任务；服务器、数据库、队列和 Worker 仍需运行。服务停止期间不能继续处理，恢复后的任务状态以任务中心为准。

任务可能处于排队、运行、暂停、取消中、成功、失败或超时状态。在任务中心打开某个项目的任务分类，可以对符合条件的任务使用「暂停全部」「启动全部」和「取消全部」；失败任务按工作台提供的操作重试。取消请求不一定立即完成。LLM 暂不可用造成的暂停与手动暂停不同，请查看状态说明和错误信息。失败时记录项目、章节、任务编号和错误，交给管理员排查。

### 我的资源

「我的资源」分为「成品」「制作资料」「存储管理」。成品可试听、单文件下载或选择范围后打包；制作资料用于检查并返回工作台，包括原稿、章节、解析 JSON、角色资料和合成片段，不提供下载或打包。

成品资格取决于可靠的成功交付记录和当前文件身份，不能仅看文件是否位于某个输出目录。缺少片段的部分合并及其后续混音不开放下载；没有可靠历史产出记录的旧文件也可能仍显示为制作资料。任务完成后资源清单还需要更新，必要时点击「更新清单」。

导出包保留 7 天，来源项目移入回收站后不可继续下载。ZIP 是成品合集，不是可以恢复项目的完整备份；项目备份按[运维指南](operations.md)同时保存数据库与工作空间。

### 存储、回收站与额度

存储清理只处理允许的临时或缓存目录中超过 7 天的普通文件；正式文本、角色资料、音频、BGM 资料、配置和日志不在清理范围。先检查候选明细，执行时系统还会复核文件资格与活动任务，实际释放容量可能小于预览值。已删除缓存不能恢复，取消任务也不会恢复已删除部分。

项目移入回收站后保留一个自然月，文件不会立即删除，也不会立即释放磁盘空间。需要继续制作时在回收站恢复项目；不要把回收站当成独立备份。

「使用量」展示可用额度、TTS 任务已预留的额度、实际消耗和明细。LLM 按最终有效输出量计量；TTS 按实际输入预留，对成功合成部分扣减，并退回未执行部分。Prompt、Token、请求次数和音频时长不作为这里的计费口径。额度由管理员配置；资源扫描、打包和清理不扣制作额度。

资源运维与备份见[运维指南](operations.md)，实现与二次开发见[开发指南](development.md)。
