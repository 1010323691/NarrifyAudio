# 手机端界面评估与适配（2026-10-06）

用户工作台与管理后台共用 Vue 界面；后端目录没有独立 HTML/CSS 页面。本次只修改显示与浏览器验收，不修改 API、任务或数据库行为。

## 范围与调整

| 界面 | 评估结果与调整 |
| --- | --- |
| 公共导航与账户菜单 | 手机导航从三行收紧为品牌/账户一行、横向导航一行。账户浮层按视口定位，避免裁切。 |
| 登录、注册、无权访问 | 保留居中与内容滚动；登录卡片收紧内边距，输入字体 16px，按钮保留触控尺寸。 |
| 项目、回收站、使用量、设置 | 延续已有窄屏布局，统一页面纵向滚动、标题、边距和控件尺寸。 |
| 项目制作总览 | 阶段名称与状态保留两列，进度另起一行；后续操作通过页面滚动到达。 |
| 任务中心 | 阶段导航横向滑动；弹窗内名称、时间、进度、详情分行展示，取消手机端 900px 最小行宽。 |
| 排版与分册、文本解析 | 表格保留全部列并允许横向滚动；筛选横向滑动，简化手机分页，沿用详情抽屉。 |
| 角色配音、音频合成、音频合并、背景音乐 | 工作台高度随工具栏增长，列表保留 320px 高度，避免批量操作挤掉内容；沿用详情抽屉。 |
| 整章预览 | 章节、台词、编辑面板纵向排列；语气浮层限制在手机视口内并允许滚动。 |
| 我的资源 | 延续容器断点；页签、统计、分页及预览/操作按钮可滚动或换行。 |
| 管理总览、性能、用户、资源、任务/队列、日志/异常 | 指标两列、服务卡片单列，筛选换行，表格局部滚动，详情收紧内边距。 |
| 系统配置、GPU 调度、音乐库管理 | 检查全部六个配置分类；沿用窄屏单列表单和音乐列表滚动，统一控件尺寸。 |
| 公共弹窗与通知 | 弹窗限制高度、长内容可滚动、长路径换行，照顾底部安全区域。 |

## PC 显示保护

适配集中在 `src/styles/mobile.css`，仅在宽度 ≤600px，或宽度 ≤880px 且高度 ≤500px 的触控横屏下启用。新增分页当前页文本在其他尺寸隐藏。桌面侧边栏、表格列、字体与工作台视口规则保持原样。

针对修改前 HEAD 的隔离副本，以相同模拟数据比较 1024px 与 1440px 下全部路由的侧边栏、内容区、标题、摘要、工作台、预览网格和指标网格边界，共 52 组，主要布局尺寸一致。实时更新时间和加载动画不用于像素一致性判断。

## 可重复验收

新增 `npm run test:mobile-layout`。先启动 Vite，再运行脚本；需要可用的 Playwright 包与 Chromium。已有工具环境可通过 `PLAYWRIGHT_MODULE_PATH` 指定包路径，无需写入仓库。无需真实登录或启动数据服务。

```bash
npm run dev
# 在另一个终端中运行：
npm run test:mobile-layout
```

可选环境变量：

- `PLAYWRIGHT_MODULE_PATH`：已有 Playwright 包路径，默认使用项目可解析的 `playwright`。
- `NARRIFY_LAYOUT_URL`：Vite 地址，默认本机 5173 端口。
- `NARRIFY_LAYOUT_SCREENSHOTS`：390px 截图输出目录；不提交生成的截图。

脚本拦截全部 `/api/` 请求，使用隔离夹具。覆盖 320×640、390×844、600×900、844×390 触控横屏、1024×900、1440×900，共 156 组路由/视口组合，并检查账户浮层、分页、任务弹窗、工作台抽屉、整章编辑、资源预览及全部系统配置分类。密集表格/导航的局部横向滚动是有意保留的。

浏览器模拟验收使用 Chromium；尚未进行真实 iOS Safari/Android 设备和软键盘验收。
