## 已锁定的行为

- 全部 15 项属于目标，不延期或用更小范围替代。
- 停机统一升级，兼容旧工作空间与历史数据，不支持旧 Worker 并行写入。
- 重型混音预检由 Worker 执行；接口返回稳定批次回执，任务报告逐章错误。
- 保留任务独立取消、暂停、重试、租约 fencing、额度和可恢复成果发布。
- 批量操作每批最多 1000 个条目，前端顺序分批并保存原幂等键恢复回执。
- 以全量后端套件 `-n 4 --dist loadscope`、前端构建/相关回归、分层检查和隔离压力证据共同验收。

## 最终审核门禁

- 各阶段实现、迁移与旧数据兼容均有直接证据。
- 四机械 Worker、1000 个音频任务不突破全机许可数；进程退出未知时不回收许可。
- 合并边界停顿及音频样本一致性；多 GB ZIP 使用有界内存。
- BGM 单章读写、角色局部样本与定向失效，不重复处理整书。
- 1000 个任务批量提交的 SQL/事务/唤醒预算及幂等恢复。
- 文件碰撞、最新交付资格、部分结果、历史别名及删除/覆盖均保持正确。
- 持续轮询下进度重算不突破刷新间隔，时长缓存避免重复探测。
- 维护恢复不会遗漏后排失效租约，Redis 至少一次派发仍保持幂等。
- PostgreSQL、真实子进程和 Windows 验收范围逐项明确；缺失环境证据不宣称完成。
- 当前源码、测试结果、PR 状态与交付文件逐项重新检查后，才报告整个计划完成。

## 原子批次后端：当前实现与剩余工作

- 文本解析（新版及旧入口）、角色基础/克隆、BGM 分析/匹配/混音使用同一原子批次协议。配置在 TaskBatch 保存一次，任务及事件按 100 条分块写入，项目行锁覆盖冲突检查至整批提交；每批最多 1000 个目标。

## 定向发布与当前交付索引：阶段 6

- 迁移 `0026_project_file_keys` 以 100 条分块回填规范化 object-key 摘要，索引非唯一，保留全部碰撞记录；ORM 赋值、批量插入及项目改名同步维护。固定 64 字符摘要避免 Unicode 大小写展开与 PostgreSQL B-tree 大小限制；原始路径不变。
- 完成事务只查询本次目标键；普通成果采用 attempt 独立命名和单目标冲突检查，不再读全项目文件表或枚举输出目录。历史碰撞拒绝覆盖；旧名字的来源兼容核验保留。`book.split` 为移除本次不再产生的旧章节仍读取相应模块，这是全书分册发布本身需要的范围。
- 迁移 `0027_current_delivery` 新增 CurrentDelivery 和 DeliveryIndexState。交付权威/撤销状态随 TaskResult 同一事务写入，记录任务、路径、身份和完成时间；新结果不会被晚回填的旧历史覆盖。较新的不完整结果对消失的路径也留撤销记录，文件重新出现不恢复旧资格。
- API 在回填完成标记前保留历史兼容读取，不启动迁移；机械 Worker 的全机单所有者维护线程按 100 条恢复回填，游标与索引同事务。项目彻底删除一并清理索引与状态。该线程将在阶段 7 与恢复、Outbox 和保留清理统一协调。
- 单文件资格查询按路径读取索引并检查当前文件身份。资源中心、混音、分集源检查改为定向查询；普通 ZIP/BGM ZIP 在每文件复制前及归档结束后重新验证资格和版本，资源归档结束时再次复核全部选中源，避免字节不变但资格被撤销时发布归档。

## 探测缓存与 Outbox pipeline：阶段 7 的部分实现

- API、BGM 和音频引擎共用持久化 SQLite 时长缓存；键包含绝对路径、五项文件身份、实际 ffprobe 工具身份和参数。只缓存前后身份稳定的正有限成功结果，失败不缓存；跨进程单飞，等待和探测期间不持有数据库连接。
