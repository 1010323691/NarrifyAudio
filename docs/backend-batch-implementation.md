## 已锁定的行为

- 全部 15 项属于目标，不延期或用更小范围替代。
- 停机统一升级，兼容旧工作空间与历史数据，不支持旧 Worker 并行写入。
- 重型混音预检由 Worker 执行；接口返回稳定批次回执，任务报告逐章错误。
- 保留任务独立取消、暂停、重试、租约 fencing、额度和可恢复成果发布。
- 批量操作每批最多 1000 个条目，前端顺序分批并保存原幂等键恢复回执。
- 以全量后端套件 `-n 4 --dist loadscope`、前端构建/相关回归、分层检查和隔离压力证据共同验收。

## 最终审核门禁

- 各阶段实现、迁移与旧数据兼容均有直接证据。
- 四机械 Worker、1000 个音频任务不突破全机许可数；进程退出未知时不回收许可。
- 合并边界停顿及音频样本一致性；多 GB ZIP 使用有界内存。
- BGM 单章读写、角色局部样本与定向失效，不重复处理整书。
- 1000 个任务批量提交的 SQL/事务/唤醒预算及幂等恢复。
- 文件碰撞、最新交付资格、部分结果、历史别名及删除/覆盖均保持正确。
- 持续轮询下进度重算不突破刷新间隔，时长缓存避免重复探测。
- 维护恢复不会遗漏后排失效租约，Redis 至少一次派发仍保持幂等。
- PostgreSQL、真实子进程和 Windows 验收范围逐项明确；缺失环境证据不宣称完成。
- 当前源码、测试结果、PR 状态与交付文件逐项重新检查后，才报告整个计划完成。

## 已取得的隔离证据

- 机械许可、GPU 与真实子进程相关回归：113 passed、1 skipped；尚未完成 Windows 原生进程控制验收。
- ZIP、命名与交付相关回归：152 passed、1 skipped。
- 两级流式合并与停顿相关回归：48 passed；包含 8/16/24/32-bit、变采样率、单/双/多声道、不同分批大小和整批缺失的旧实现逐样本比较。
- 实际 audio.zip 执行器，2 GiB 输入：ZIP 2,147,483,884 字节，额外峰值 RSS 2,240,512 字节；CRC 和 SHA-256 通过。
- 实际 audio.zip 执行器，8 GiB 输入：ZIP 8,589,934,828 字节，额外峰值 RSS 2,187,264 字节；ZIP64、CRC 和 SHA-256 通过。
- 大归档测量使用临时目录和稀疏零输入，走实际文件复制与摘要路径；未经过数据库领取/最终发布，不作为端到端或 Windows 吞吐承诺。
- 100 段两级合并，最终音频 2012.169 秒（约 33.5 分钟），全部 PCM 样本及 99 处边界停顿逐块验证，额外峰值 RSS 2,056,192 字节。
- RF64 实际写出 4,294,968,400 字节；ffprobe 确认 2,147,484,160 帧，额外峰值 RSS 696,320 字节。
- 最终全量后端：1559 passed、23 skipped（含 MP3 输入磁盘解码回归）；`npm run build:all` 通过（含前端类型检查/构建、后端编译与导入分层门禁）。Python 3.13+ 显式声明 audioop-lts，避免依赖本机偶然安装的间接包。

大文件隔离验收可重跑：

```bash
.venv/bin/python scripts/verify_disk_zip.py 2
.venv/bin/python scripts/verify_disk_zip.py 8
.venv/bin/python scripts/verify_pcm_stream.py long
.venv/bin/python scripts/verify_pcm_stream.py rf64
```

脚本使用临时目录，执行结束清理，记录实际 RSS 与输出校验；不访问应用数据库或用户工作空间。
